# AI collaboration / handoff

Work in small branches and PRs. One task, one owner, explicit acceptance criteria and test results.

- `TASKS.md`: task board; status with owner and dependencies.
- `IMPLEMENTATION.md`: implementation log by coding agent.
- `REVIEW.md`: independent reviewer findings and merge recommendation.

Status values: TODO, IN_PROGRESS, BLOCKED, REVIEW, DONE.
Do not change religious source text without immutable-source comparison. Do not claim tests ran unless tool output proves that they ran. Do not merge content without the required human scholarly review.
