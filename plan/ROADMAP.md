## الإصدارات المتوقعة
- بعد Phase 00: Prototype تقني لبنية التطبيق.
- بعد Phase 01: Android MVP قابل للاستخدام بالمصحف والصلاة والقبلة والتفسير والصوت المرخص.
- بعد Phase 02: تجربة عبادات يومية موسعة.
- بعد Phase 03: مكتبة الحديث والفقه المراجع علميًا.
- بعد Phase 04: المحتوى التعليمي وCMS.
- بعد Phase 05: نسخة Beta اجتازت اختبارات الأمان والجودة.
- في Phase 06: Google Play والنشر والصيانة واستعداد iOS.

## المسار الحرج
`مصدر مصحف مرخص` → `نسخة قرآن ثابتة + فحص 100%` → `MVP`.

`إذن بث وتخزين` → `مشغل صوت` → `توسيع القراء`.

`مراجع شرعي مؤهل` + `مصادر مرخصة` → `اعتماد الفقه` → `الظهور للمستخدم`.

`Prayer calculation fixtures` → `وقت الصلاة والقبلة` → `إشعارات آمنة`.

## قواعد التغيير
كل توسع جديد يأخذ Task ID وPhase وAcceptance وDependency قبل التنفيذ. يتم تحديث [DECISIONS.md](DECISIONS.md) و[TRACKER.md](TRACKER.md) في نفس PR. لا تُغلق مرحلة لمجرد أن شاشاتها موجودة.
