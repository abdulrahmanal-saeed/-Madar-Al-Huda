## الثوابت
- Android (Flutter) أولًا، ثم iOS، **العربية والإنجليزية من البداية**.
- مجاني بالكامل بلا إعلانات أو اشتراكات، حساب المستخدم اختياري.
- القرآن قراءة واستماع، والطبري وابن كثير للتفسير كمرشحين بعد إثبات الحقوق.
- القراء المستهدفون: ماهر المعيقلي، محمود علي البنا، إسلام صبحي، حسب تراخيص التسجيلات.
- مقارنة فقهية موثقة للمذاهب الأربعة مع **اعتماد عالم مؤهل قبل النشر**.
- مواقيت الصلاة حسب الموقع أو مدينة يدوية، وأول اختبار في الإمارات ومصر.
- المكتبة: الحديث والأذكار والأدعية والدروس وقصص الأنبياء والمقالات والمقتبسات.
