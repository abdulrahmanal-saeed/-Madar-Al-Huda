# Religious editorial and publication governance

## Roles
Contributor -> Source verifier -> Qualified scholarly reviewer -> Language reviewer (AR/EN) -> Publisher.
One individual may hold multiple roles if qualified, but approval events must identify the actual responsible reviewer. Public release of jurisprudential explanations requires qualified review.

## Four Sunni madhhabs
- Present Hanafi, Maliki, Shafi'i and Hanbali in a consistent, non-polemical order.
- A madhhab may have multiple transmitted views. Record whether a view is relied-upon, prominent, disputed, or preliminary **only if a source and reviewer support that label**.
- Include topic, scope, conditions, exceptions, classical reference and edition/locator.
- Coverage status: not researched / drafting / awaiting review / verified / withdrawn.
- No claim of consensus when a school has missing coverage.
- Personal circumstances requiring a fatwa: direct users to a qualified mufti rather than infer a ruling automatically.

## Quran, tafsir, hadith
- Quran source text must be cryptographically checked against a fixed approved release.
- Tafsir attributed to correct scholar and digital edition; translations not misrepresented as original text.
- For hadith, record collection and reference, narrator where available, grade *and grader/source* when grading applies.
- Prophet stories must distinguish sourced Qur'an/Sunnah material from uncertain historical narrations.

## Editorial state machine
draft -> source_verified -> scholarly_reviewed -> language_reviewed -> approved -> published.
Any correction creates a new version with audit trail. `withdrawn` hides disputed published content promptly.

## Release quality
- No unverified citations.
- Both languages reviewed independently for doctrinal meaning.
- Source metadata visible on all relevant content pages.
- Clearly expose correction and feedback channels.
- Do not schedule notification quotes until the item has publication approval.
